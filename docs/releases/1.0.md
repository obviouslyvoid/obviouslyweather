# obviouslyweather 1.0

First public release.

Download `obviouslyweather-1.0-arm64.apk` below. It requires Android 15 or newer and an ARM64 device.

On first launch, enter your OpenWeather API key and choose a city. The key needs One Call API 4.0 access for hourly forecasts. Daily forecasts use 4.0 by default, with a manual 3.0 option in settings.

The matching source is in `obviouslyweather-1.0-source.zip`. File checksums are in `SHA256SUMS.txt`.
