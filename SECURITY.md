# Security

Report vulnerabilities through [GitHub's private reporting form](https://github.com/obviouslyvoid/obviouslyweather/security/advisories/new). Include the affected app version and enough steps to reproduce the problem. Use dummy credentials in examples.

If private reporting isn't available, open an issue asking how to send a private report. Keep the vulnerability details out of that issue.

Crashes, forecast errors and other app bugs belong in [Issues](https://github.com/obviouslyvoid/obviouslyweather/issues).
